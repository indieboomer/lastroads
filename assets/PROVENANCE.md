# Asset provenance

All illustrations are generated for this project with the **built-in image generation tool**, rather than copied from external game libraries. No external character or environment reference was supplied. The combat-pose atlas uses this project's generated enemy sheet as its design reference; the NPC cutout is an edit of its generated character sheet.

## Production assets

The November 8 revision adds individually generated trees, larger paired open/closed-eye NPC sheets, full-arm first-person equipment with the shield's inner grip visible, four types of fallen remains, and edible/inedible fantasy mushrooms. These live in **`revision/`**; exact prompts and original output paths are in **`revision/manifest.json`**. All use the built-in image generation tool. Existing project art supplied the design references. Runtime texture extraction trims atlas padding and caches the results in `.godot/sprite-cache`; it does not overwrite the original PNGs. The older atlases below remain recorded for provenance and enemy poses.

- `last-roads.png`: the original title illustration, generated on 2026-11-07.
- `trees.png`: four painted tree silhouettes.
- `props.png`: eight foliage, rock, chest and standing-stone assets.
- `npcs-cut.png`: production character atlas; `npcs.png` is the retained source generation.
- `enemies.png`: detailed ready poses for four enemy families.
- `combat.png`: wind-up, attack and recoil poses, with ready poses retained in the sheet.
- `weapon.png`: first-person sword, buckler and gloved hands.
- `ground.png`: painted forest floor.
- `material.png`: stone, plaster, timber and clay-roof material atlas.
- `sky.png`: painted panoramic sky.

The exact final prompts, edit prompts, generation method and original local output paths for the new assets are recorded in **`generated-manifest.json`**. Godot `AtlasTexture` regions select the individual sprites and materials; the game retains the generated PNGs with their alpha. Some packed atlas regions are deliberately adjusted to avoid neighbouring figures intruding at cell boundaries.

Original title-image prompt:

> Use case: stylized-concept. Asset type: title screen illustration for The Last Roads fantasy first-person game. Wide landscape painting, carved wooden miniature aesthetic, northern European forest road leading from warm amber roadside inn at left towards ruined stone watchtower in distance at right, dusk blue green pines, tiny lanterns, mist, ominous but adventurous. Strong silhouette, restrained details, painterly matte texture, beautiful composition. No text, no lettering, no watermark.

Geometry, shaders, particle effects and synthesized audio are produced by the project code. Cinzel is downloaded from the official Google Fonts repository; its SIL Open Font License is included in `fonts/OFL.txt`: https://github.com/google/fonts/tree/main/ofl/cinzel . The body font is Godot's bundled default font.

The engine is Godot 4.5.1 stable from its official release archive: https://godotengine.org/download/archive/4.5.1-stable/ . Godot's MIT license and attribution information: https://godotengine.org/license/ . The setup script pins the downloaded Windows archive by SHA-256.
